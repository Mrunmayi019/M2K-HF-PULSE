# Benchmark comparison: risk_score.py vs. MAGGIC

Generated by `scripts/benchmark_comparison.py` against `data/simulation_runs/features_dataset.csv` (n=117 successful Phase 4 batch runs, joined with `data/synthetic/patients.csv` for age/sex/BMI/NYHA).

**Read this as agreement between two model outputs, not validation against real outcomes** -- see this script's own module docstring and `src/analytics/benchmark_scores.py`'s module docstring for exactly which MAGGIC inputs are real per-patient data vs. fixed assumed defaults (age/sex/EF/NYHA/BMI are real; systolic BP, creatinine, diabetes/COPD/smoking, HF duration, and beta-blocker/ACEI-ARB use are fixed constants, not measured).

## Interpretation

A low/negative correlation would not necessarily mean either score is wrong -- risk_score.py measures acute hemodynamic response to one simulated Pulse encounter plus chronic baseline congestion (the fluid_overload fix), while MAGGIC is a static population-mortality score from clinical intake variables. They are measuring related but distinct things by design. What this comparison actually establishes: whether this project's risk output is at least directionally consistent with an externally validated score on the same patients, which is the minimum bar HANDOFF.md's P2 item asks for -- not equivalence, and not a substitute for the real clinical outcome validation in P1.
